桌面工作台

为持续使用而设计

桌面壳不改变 Harness 的插件模型，只把日常入口、窗口生命周期和平台安装体验整合到一起。

01

完整工作区

管理多个工作区和会话，在对话、轨迹与任务详情之间快速切换。

02

模型与权限

在设置页连接提供方、选择模型，并为新会话配置权限模式与 Agent 预设。

03

本地可扩展

继续使用 Cordis 插件体系、工具与配置文件，桌面版不会锁住现有工作流。

OpenCode Go

连接、导入、查看套餐用量

输入 OPENCODE_API_KEY 后验证套餐并导入官方模型。在提供方行内直接查看 5 小时、1 周与 1 月用量窗口。

开放源码

在你的平台上构建

安装包当前需要系统 PATH 中已有 dsh CLI。桌面壳与上游 Harness 放在同一个 pnpm workspace 中，准备 Node.js、Rust 和 Tauri 2 平台依赖即可开发。

npm install --global @deepseek-ai/dsh
git clone https://github.com/xiaojiecode/deepseek-harness.git
cd deepseek-harness
pnpm install
pnpm run desktop:dev
